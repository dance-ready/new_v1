## Replacing an image

Just drop a new file in this folder with the same filename — no code changes needed.
For best results match the source dimensions roughly:

- Hero / page-hero: landscape, 1600–1800 px wide
- Section/card: landscape or portrait, 1000–1200 px wide
- Founders: portrait crop, 800 px wide
- Each image: aim for under 300 KB
